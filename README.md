## What Is CSTI Game Personality Test?

CSTI Game Personality Test is a web-based quiz focused on the habits and decisions of CS2 and CSGO players. Across 35 questions, it estimates a likely rank tendency, identifies playstyle characteristics, and places the result into one of 15 personality categories.

The interface is built for fast browser use and works across desktop and mobile screen sizes. Multilingual support expands its accessibility, while audio and animation provide additional feedback during the quiz and result presentation without altering the underlying test format.
